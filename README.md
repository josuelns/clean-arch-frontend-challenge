# clean-arch-frontend-challenge

> Entregar front-end escalável e testável em desafio técnico com regras de negócio e qualidade de produção.

## Problema

Entregar front-end escalável e testável em desafio técnico com regras de negócio e qualidade de produção.

## Solução

React + TypeScript em Clean Architecture, Redux Saga para efeitos colaterais, TDD com Jest, E2E com Cypress, SOLID e pipeline preparado para Docker e CI.

## Stack

- React
- TypeScript
- Redux Saga
- Cypress
- Jest
- Docker
